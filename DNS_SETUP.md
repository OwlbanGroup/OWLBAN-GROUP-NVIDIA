# 🌐 DNS Configuration Guide for JPMorgan Financial APIs

## Overview
This guide explains how to configure DNS records to integrate the JPMorgan Financial APIs as a subdomain (api.equityshieldadvocates.com) with your existing website.

## Required DNS Records

### 1. A Record (Primary)
```
Type: A
Name: api
Value: YOUR_SERVER_IP_ADDRESS
TTL: 300 (5 minutes)
```

### 2. CNAME Record (Alternative)
```
Type: CNAME
Name: api
Value: equityshieldadvocates.com
TTL: 300 (5 minutes)
```

### 3. TXT Record (SSL Verification)
```
Type: TXT
Name: _acme-challenge.api
Value: [Generated by Certbot during SSL setup]
TTL: 300 (5 minutes)
```

## DNS Provider Specific Instructions

### Namecheap
1. Log in to your Namecheap account
2. Go to **Domain List** → **Manage** (next to equityshieldadvocates.com)
3. Click **Advanced DNS**
4. Add the following records:
   - **Type:** A Record
   - **Host:** api
   - **Value:** YOUR_SERVER_IP
   - **TTL:** 300

### GoDaddy
1. Log in to your GoDaddy account
2. Go to **My Products** → **Domains**
3. Click on **equityshieldadvocates.com** → **Manage DNS**
4. Click **Add** and create:
   - **Type:** A
   - **Name:** api
   - **Value:** YOUR_SERVER_IP
   - **TTL:** 5 minutes

### Cloudflare
1. Log in to Cloudflare
2. Select your **equityshieldadvocates.com** site
3. Go to **DNS** section
4. Click **Add record**:
   - **Type:** A
   - **Name:** api
   - **IPv4 address:** YOUR_SERVER_IP
   - **TTL:** Auto
   - **Proxy status:** DNS only (gray cloud)

### AWS Route 53
1. Log in to AWS Console
2. Go to **Route 53** → **Hosted zones**
3. Select **equityshieldadvocates.com**
4. Click **Create record**:
   - **Record name:** api
   - **Record type:** A
   - **Value:** YOUR_SERVER_IP
   - **TTL:** 300

## Troubleshooting

### DNS Not Propagating
- **Wait time:** DNS changes can take 24-48 hours to propagate globally
- **Check TTL:** Lower TTL values (300 seconds) speed up propagation
- **Clear cache:** Flush local DNS cache
  ```bash
  # Windows
  ipconfig /flushdns

  # Linux
  sudo systemd-resolve --flush-caches

  # macOS
  sudo killall -HUP mDNSResponder
  ```

### Common Issues
1. **Wrong IP address:** Double-check your server IP
2. **Typo in subdomain:** Ensure "api" is spelled correctly
3. **DNS caching:** Wait for cache expiration or flush caches
4. **Registrar issues:** Contact your DNS provider support

### Emergency Rollback
If DNS changes cause issues:
1. Remove the api subdomain record
2. Wait for propagation (can take same 24-48 hours)
3. Contact your DNS provider for immediate assistance

## Advanced Configuration

### CDN Integration
If using Cloudflare or similar CDN:
- Set proxy status to "DNS only" initially
- Enable after confirming API works
- Configure page rules for API endpoints

### Load Balancing
For multiple servers:
- Use multiple A records with same name
- Or configure CNAME to load balancer hostname
- Ensure all servers have identical configuration

### Monitoring
Set up monitoring for DNS changes:
```bash
# Add to cron for daily checks
*/30 * * * * curl -s https://api.equityshieldadvocates.com/health > /dev/null || echo "API DOWN" | mail -s "API Alert" admin@equityshieldadvocates.com
```

## Security Considerations

- **DNSSEC:** Enable DNSSEC if supported by your provider
- **Monitoring:** Set up alerts for DNS record changes
- **Backup:** Document all DNS records in a secure location
- **Access control:** Limit who can modify DNS records
