Quick Reference

Authentication

All API endpoints require authentication. Use Bearer tokens in the Authorization header:

Authorization: Bearer your_token_here

Response Format

All responses are in JSON format with a consistent structure:

{ "status": "success|error", "data": { ... }, "timestamp": "ISO 8601 timestamp" }

Error Handling

Error responses include detailed error messages:

{ "error": "Error description", "status": "error", "timestamp": "ISO 8601 timestamp" }
