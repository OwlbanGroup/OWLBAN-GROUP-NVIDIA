## Troubleshooting

### Issue: Containers Won't Start

**Check Docker:**
```powershell
docker info
```

**Solution:**
- Ensure Docker Desktop is running
- Check available disk space (need ~5GB)
- Check available memory (need ~4GB)

### Issue: Port Already in Use

**Find process:**
```powershell
netstat -ano | findstr :80
netstat -ano | findstr :8000
```

**Solution:**
- Stop the conflicting process
- Or change ports in docker-compose.production.yml

### Issue: Login Still Fails

**Check NGINX logs:**
```powershell
docker logs jpmorgan-nginx-prod --tail 50
```

**Check API logs:**
```powershell
docker logs jpmorgan-api-prod --tail 50
```

**Solutions:**
1. Clear browser cache (Ctrl+Shift+Delete)
2. Hard refresh (Ctrl+F5)
3. Verify NGINX config:
   ```powershell
   docker exec jpmorgan-nginx-prod nginx -t
   ```
4. Restart NGINX:
   ```powershell
   docker restart jpmorgan-nginx-prod
   ```

### Issue: Database Connection Error

**Check PostgreSQL:**
```powershell
docker logs jpmorgan-postgres-prod --tail 50
```

**Test connection:**
```powershell
docker exec -it jpmorgan-postgres-prod psql -U jpmorgan_prod -d jpmorgan_financial_apis_prod
```

**Solution:**
- Wait for database to fully initialize (30-60 seconds)
- Check DATABASE_URL in .env.production
- Verify password is URL-encoded: `SecureP%40ssw0rd2024`

### Issue: 502 Bad Gateway

**Cause:** API container not running or not ready

**Check API status:**
```powershell
docker ps | findstr jpmorgan-api-prod
```

**Solution:**
1. Check API logs for errors
2. Restart API container
3. Verify .env.production exists
4. Check database connection

### SSL/TLS Setup

**Generate self-signed certificates (testing):**
```bash
cd nginx/ssl
openssl genrsa -out server.key 2048
openssl req -new -key server.key -out server.csr
openssl x509 -req -days 365 -in server.csr -signkey server.key -out server.crt
```

**Use Let's Encrypt (production):**
```bash
certbot certonly --standalone -d yourdomain.com
cp /etc/letsencrypt/live/yourdomain.com/fullchain.pem nginx/ssl/server.crt
cp /etc/letsencrypt/live/yourdomain.com/privkey.pem nginx/ssl/server.key
```
